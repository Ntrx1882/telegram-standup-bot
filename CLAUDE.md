## Структура репозитория (важно)

Исходный код проекта **не** лежит распакованным в корне. В корне есть только:

- `README.md` — однострочная заглушка (`# telegram-standup-bot`).
- `telegram-standup-bot.zip` — настоящий проект, внутри `standup_bot.py` и более полный `README.md`.

Перед работой над ботом распакуйте архив (например, `unzip telegram-standup-bot.zip`). Подробный README с зависимостями и инструкцией по запуску — это копия **внутри** zip, а не заглушка в корне. Если вносите изменения в код, осознанно решайте, куда они идут: в распакованный корень, внутрь zip или в оба места — текущая упаковка нестандартна и в ней легко ошибиться.

## О проекте

Минимальный Telegram-бот для сбора ежедневных стендап-апдейтов от участников команды. Построен на `python-telegram-bot` v20+ с использованием его асинхронного API. Текущая версия — базовый скелет: подтверждает получение апдейта, но пока не сохраняет данные и не пересылает сводки в групповой чат.

## Команды

- Установка зависимости: `pip install python-telegram-bot --upgrade` (требуется Python 3.10+)
- Запуск бота: `python standup_bot.py`
- Токен берётся из переменной окружения `TELEGRAM_BOT_TOKEN`. Без неё запуск упадёт.

В репозитории нет настроенной сборки, тестов и линтера.

## Архитектура

`standup_bot.py` — единственная точка входа:

- Асинхронные обработчики команд (`start`, `update_status`), зарегистрированные через `CommandHandler` на приложении `ApplicationBuilder`.
- `update_status` читает сообщение пользователя через `context.args` и сейчас только отправляет подтверждение — комментарий `# Здесь должен быть сбор и отправка данных` отмечает место, куда планируется логика сохранения/пересылки.
- Приложение работает через `app.run_polling()` (long polling, без webhook).
- Часть комментариев в коде — на русском.

## План развития (из README внутри zip)

Запланировано, но не реализовано: сохранение апдейтов в файл/БД, формирование ежедневных сводок, отправка сводок в групповой чат и расписание ежедневных запросов. При расширении бота это и есть намеченные направления.
